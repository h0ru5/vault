# Obsidian vault

This repository is the root of an Obsidian vault. Clone the repository, then
open its folder in Obsidian (or create your notes here if you already have it
open as a vault).

## Syncing

Use Git to sync this vault between devices: commit and push changes from one
device, then pull before working on another. You can do this with a Git client
or an Obsidian Git community plugin. Avoid editing the same note on multiple
devices before syncing, to reduce merge conflicts.

Notes and vault configuration are tracked. Machine-specific workspace state
and common operating-system files are excluded in `.gitignore`.
